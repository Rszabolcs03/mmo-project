Getting started

Download the installer

II

Run the setup

Pick an install folder and let it finish. Windows SmartScreen may warn you — see the FAQ below.

Good to know

Frequently asked questions.

Windows says the publisher is unknown. Is that normal?

Yes. Wayworn is an early indie build and the installer is not code-signed yet, so SmartScreen shows a warning. Click “More info” and then “Run anyway” if you downloaded the file from this page.

Do I need to re-download every new version?

No. The client checks for updates when it starts and downloads new builds automatically. You only need the installer once.

Is my progress tied to my PC?

No — characters are saved to your Wayworn account in the cloud. Reinstalling Windows or switching machines will not lose your heroes, as long as you sign in with the same account.

What should I expect from a playtest build?

Rough edges: placeholder art in spots, balance swings, and the occasional bug. The world grows with nearly every build — that is the fun of testing early. Feedback is very welcome on Instagram.

Will there be a Mac or Linux version?

Windows is the focus right now. The client groundwork for other platforms exists, but there is no promised date for them yet.
