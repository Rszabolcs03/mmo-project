# Adventurer Fresh v2 archive

This is the complete pre-profile-rework snapshot taken on 2026-08-09 before
the live character models were regenerated as `adventurer-fresh-v3`.

- `assets/` contains all five former live race roots exactly as they existed.
- `source/` contains the generator, validators, contact-sheet renderers, and
  runtime/UI integration files that selected and layered those assets.
- The game does not load this directory. It is retained only for recovery and
  visual comparison.
