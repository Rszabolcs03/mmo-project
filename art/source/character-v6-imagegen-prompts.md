# Character v6 visual target prompts

The two visual targets in this folder were generated with the built-in image generation
tool from the user's supplied reference images. They are style and construction targets;
the live sprites are produced deterministically by the project generator.

## Eight-direction wizard target

```text
Use case: stylized-concept
Asset type: production direction-and-proportion reference for a modular 2D MMORPG pixel-character generator
Input images: Image 1 is the current functional eight-direction character sheet; use it only for the required compass-direction order, centered feet, equipment readability, and compact frame occupancy. Image 2 is the primary visual-style reference; closely follow its rounded chibi proportions, large expressive eyes, soft friendly face, clean dark-brown outlines, richer blue cloth shading, gold piping, layered robe shapes, decorated wizard hats, polished boots, and charming high-quality pixel clusters. Create original artwork rather than copying any one reference character.
Primary request: design one original human wizard as a coherent eight-direction turnaround: front, front-right, right profile, back-right, back, back-left, left profile, front-left.
Subject: same young adult wizard in every view; large but controlled rounded head; short compact body; navy pointed hat with gold band and small original star motif; layered navy/cobalt robe with gold trim and belt; brown boots; wooden staff with cyan crystal; relaxed neutral pose.
Style/medium: polished hand-authored fantasy RPG pixel art in the visual direction of Image 2; cute and premium; deliberate 1–3 pixel clusters; subtle three-tone shading; readable at approximately 48x64 pixels per character; no soft painting or vector smoothness.
Composition/framing: eight equal cells in a single horizontal turnaround sheet, identical scale and foot baseline, ample padding, no overlap.
Lighting/mood: warm friendly upper-left lighting with consistent highlight placement.
Constraints: identical head size, costume construction, staff proportions, and anatomy in all eight views; profiles have a rounded forehead, small nose, cheek, and chin; rear diagonals correctly hide facial features; hat cone and brim rotate believably; staff changes overlap/depth correctly; no text, labels, UI, logos, or watermark.
Avoid: flat mask faces, blank circular heads, giant weapons, thin realistic bodies, inconsistent hat shapes, mirrored facial errors, facial features on rear views, magenta background from the reference.
```

## Six-class lineup target

```text
Use case: stylized-concept
Asset type: production class-silhouette reference for a modular 2D MMORPG pixel-character generator
Input images: Image 1 is the current functional game sheet; use it only for approximate frame occupancy and equipment readability. Image 2 is the primary visual-style reference; follow its expressive rounded faces, large eyes, clean warm outlines, layered garments, gold details, soft three-tone pixel shading, compact chibi anatomy, polished boots, and ornate but readable fantasy design. Create original class designs rather than copying the shown wizards.
Primary request: create a front-facing character lineup for six original human adventurer classes: mage, hunter, paladin, warrior, priest, and rogue.
Subject: six distinct young adult heroes at identical scale and neutral pose. Mage: pointed navy hat, layered blue robe, crystal staff. Hunter: forest-green hood/cap, leather jerkin, short capelet, bow and quiver. Paladin: ivory-and-gold plate, blue tabard, sword. Warrior: steel and crimson plate, broad sword. Priest: ivory robe, gold stole, rounded ceremonial hood, staff. Rogue: charcoal-violet hood, layered leather, twin daggers.
Style/medium: premium hand-authored fantasy RPG pixel art matching the visual direction of Image 2; expressive friendly faces; rounded compact silhouettes; deliberate 1–3 pixel clusters; three-tone cloth/metal/leather shading; crisp dark-brown/navy outlines; approximately 48x64 pixels per character.
Composition/framing: six equal cells in one horizontal lineup, same scale and foot baseline, generous padding, no overlap.
Lighting/mood: warm upper-left game-sprite lighting.
Constraints: each class must be instantly recognizable from silhouette and materials; faces and body proportions remain part of one shared character system; equipment remains secondary to the character; no text, labels, UI, logos, watermark, or magenta background.
Avoid: recolored identical outfits, flat geometric torsos, oversized weapons, blank faces, photorealism, soft painting, 3D rendering, inconsistent character scale.
```
