# Character model v4 archive

This folder preserves the character system that was live immediately before the v5 remodel.

- `scripts/generate-human-fresh-assets-v4.mjs` is the previous procedural generator.
- `assets/*_fresh/` contains the generated human, elf, dwarf, orc, and undead paper-doll atlases and manifests.
- `art-reference/` contains the v4 contact sheets used to diagnose the old head, profile, and customization problems.

The runtime does not read this directory. The active replacement remains under `public/assets/characters/*_fresh/` and is generated by `scripts/generate-human-fresh-assets.mjs`.
